# ที่มาของภาพใน Style Kit

ภาพทั้ง 6 ใบในโฟลเดอร์นี้ **วาดใหม่ใน ChatGPT web บัญชีเจ้าของโปรเจกต์ เมื่อ 22 พ.ย. 2026**
prompt ที่ใช้ทุกใบ (และรายการภาพอ้างอิงที่แนบตอนสร้าง) บันทึกไว้ที่ `docs/design/phi-style-kit.prompt.txt`

- ภาพปกเล่มจริงในเครื่อง (`references/`) ใช้เป็นแบบ **เทคนิคลายเส้น/ลงสี เท่านั้น** ตอนสร้างภาพ — **ไม่ได้ส่งไปกับแอป** ไม่ได้อ้างใน `kit.json` และไม่ได้ commit
- ภาพที่ส่งไปกับแอปคือ JPEG ย่อ 768x1152 (ไม่เกิน 400 KB ต่อใบ) ต้นฉบับ PNG 1024x1536 เก็บใน `assets/style-kit-raw/` (อยู่ใน git แต่ไม่ส่งให้ลูกค้า)
- JPEG สร้างด้วย `node scripts/build-style-kit.mjs` — แก้สีด้วยตัวเดียวกับ inkify (ปรับขาวให้เป็นกลาง + ความสด 1.15) เพราะต้นฉบับออกโทนกระดาษเหลือง/ซีเปีย (ผู้ใช้ตัดสิน 22 พ.ย.: ภาพต้องไม่ออกเหลือง) · ต้นฉบับ PNG ไม่ถูกแก้
