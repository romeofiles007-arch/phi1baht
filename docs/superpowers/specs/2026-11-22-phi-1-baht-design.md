# ผี 1 บาท — เอกสารออกแบบ

วันที่ 22 พ.ย. 2026 · สถานะ: ร่าง รออนุมัติ

## 1. เจตนา

ทำคลิปเรื่องผีสั้น **ยาวประมาณ 1 นาที เล่าจบในคลิป** ด้วย**ลายเส้นการ์ตูนไทยเล่มละบาท** (ยุคทอง พ.ศ. 2520–2540) แบบอัตโนมัติ
ใช้ระบบเดียวกับ "ตำนานจีน Auto" (`E:\China`) ทุกขั้น ตั้งแต่หัวข้อไปจนถึงโพสต์ แต่เปลี่ยนเนื้อหา ลายเส้น และธีมหน้าตาเป็นผีไทยเล่มละบาท
ชื่อผลิตภัณฑ์: **ผี 1 บาท**

ภาพอ้างอิงลายเส้นต้นฉบับอยู่ที่ `references/` ภาพที่สำคัญที่สุดคือ `destudio_1.jpg` เป็นหน้าต้นฉบับลงหมึกของลุงอร (อภิชาต รอดวัฒนกุล) อีกภาพคือ `momentum_2.jpg` เป็นผีกระสือของครูโต๊ด โกสุมพิสัย

## 2. เป้าหมาย / ไม่ทำ / ล้มเหลวแม้ทำงานได้

**เป้าหมาย**
- ส่วนขยาย Chrome (MV3 แผงข้าง) และโปรแกรมในเครื่องชื่อ "ผี 1 บาท" ที่ทำงานครบทุกแผนกเหมือน China ได้แก่ เขียนบท (ChatGPT web), เสียงพากย์, กำกับภาพ (ChatGPT web), วาดภาพ (Google Flow), แอนิเมชัน Kie (ตั้งต้นปิด), ตัดต่อ (ffmpeg) และโพสต์ TikTok/แพลตฟอร์มอื่น
- คลิปความยาวตั้งต้น 1 นาที มีต้น กลาง จบ และมีจังหวะสะดุ้งหรือหักมุมตอนท้าย เรื่องผีเป็นหมวดหลัก และมีหมวดอื่นตามแนวการ์ตูนเล่มละบาท (ข้อ 5.3)
- ภาพทุกช็อตเป็นลายเส้นหมึกเล่มละบาท และภาพปกเป็นแบบปกเล่มละบาท
- ติดตั้งและเปิดใช้พร้อมกับ China และโปรเจกต์พี่น้องอื่นบนเครื่องเดียวกันได้

**ไม่ทำ**
- ไม่แก้ไฟล์ใดใน `E:\China`
- ไม่รวมโค้ดกับ China เป็นแกนกลางร่วม (แนวทาง ค ถูกตัดออก)
- ไม่ใช้ ChatGPT วาดภาพในคลิป ภาพในคลิปให้ Flow วาดเหมือนเดิม
- ไม่ดึงประวัติหรือภาพบุคคลจริงจากวิกิพีเดีย เพราะเรื่องผีเป็นเรื่องแต่ง

**ถือว่าล้มเหลวแม้ระบบทำงานได้**
- ภาพออกมาเป็นอนิเมะ มังงะ การ์ตูนฝรั่ง 3D หรือ doodle แทนที่จะเป็นหมึกไทยเล่มละบาท
- เรื่องยาวเกิน 1 นาทีไปมาก หรือจบแบบค้าง "ติดตามตอนต่อไป"
- ไปแย่งแท็บ ChatGPT/Flow หรือพอร์ตของ China จนอีกตัวพัง
- มีภาพโป๊หรือเปลือย หรือเลือดสาดจน Flow หรือ TikTok ปฏิเสธ
- คำว่า ตำนานจีน / China / ธรรมะ หลงเหลือในสิ่งที่ผู้ใช้เห็น

## 3. แนวทางที่พิจารณา

| | แนวทาง | ข้อดี | ข้อเสีย |
|---|---|---|---|
| **ก (เลือก)** | ก๊อป China มาเป็นโปรเจกต์ใหม่แล้วเปลี่ยนตัวตน | China ไม่ถูกแตะ ใช้คู่กันได้ ได้คลิปแรกเร็วที่สุด | มีโค้ดสองชุด บั๊กที่แก้ใน China ต้องตามมาแก้เอง |
| ข | เพิ่มเป็นหมวดที่ 4 ใน China | ติดตั้งตัวเดียว | กฎ China ขัดกันตรง ๆ (ห้ามเลือด บังคับโทนเย็น ห้ามกระดาษเหลือง ธีมจีน) ต้องแยกกฎตามหมวดแทบทุกไฟล์ เสี่ยงทำ China พัง |
| ค | รื้อ China เป็นแกนกลาง แล้วทำธีมเป็นชุดเสียบ | ระยะยาวดีที่สุด | รื้อระบบที่ใช้งานจริงก้อนใหญ่ก่อนได้คลิปผีคลิปแรก |

ผู้ใช้เลือก **ก** ซึ่งเป็นแบบที่ใช้กันมาแล้วในโปรเจกต์ชุดนี้ (ตัวต้นฉบับ YouTube → ธรรมะ → China ล้วนก๊อปต่อกันมา)

## 4. สิ่งที่ผู้ใช้ตัดสินแล้ว

- ชื่อ "ผี 1 บาท"
- ลายเส้นตามการ์ตูนไทยเล่มละบาท
- เรื่องผีเล่าจบภายใน 1 นาที
- ChatGPT web เขียนบทและกำกับภาพ ส่วน Google Flow วาดภาพเหมือนเดิม
- **ภาพธีมของส่วนขยาย สั่งทำใน ChatGPT web แล้วดึงมาใส่** ได้แก่ ไอคอน ตัวละครประจำแผนก และฉากพื้นหลัง ทำแบบเดียวกับ China คือเขียน prompt ใน `docs/design/*.prompt.txt` → สร้างภาพใน ChatGPT web → เก็บไว้ที่ `assets/<ชุด>-raw/` → รัน `scripts/build-icons.py`
- ก๊อปแยกเป็นโปรเจกต์ใหม่ (แนวทาง ก) โดยผี 1 บาทเป็นแอปแยก และ China เป็นแค่แบบอย่าง
- ทำเป็นชุดติดตั้ง Setup.exe ให้ลูกค้า
- ผลิตพร้อมกับ China ได้ เพราะใช้บัญชีแยกกัน
- มีหมวดอื่นนอกจากเรื่องผี
- ให้คิดฟีเจอร์ใหม่ให้เหมาะกับแอป
- ลายเส้นและสีต้องเหมือนเล่มละบาทจริงมากที่สุด

## 5. การออกแบบ

### 5.1 ก๊อปและเปลี่ยนตัวตน

- **ไม่ก๊อป:** `.env`, `projects/`, `runtime/`, venv ของเสียง, เสียงที่เทรนไว้, `bridge/*.log`, `bridge/jobs*.json`, `characters/`, `dist/`, `refs/`, `.impeccable/`, `setup.exe` (ส่วนใหญ่ถูก git ignore อยู่แล้ว)

### 5.2 แท็บ ChatGPT / Flow เมื่อรันคู่กับ China

China เลือกแท็บดังนี้ (ตรวจจากโค้ดแล้ว)
- **ChatGPT:** `ensureTab()` ใช้แท็บที่บันทึกไว้ใน `storage.session` ก่อน ถ้าไม่มีจะหยิบแท็บไหนก็ได้ ค่าที่บันทึกนี้หายทุกครั้งที่เปิด Chrome ใหม่หรือส่วนขยายรีโหลดตัวเองหลังอัปเดต
- **Flow:** `preferredFlowTab()` หยิบแท็บ Flow ที่เพิ่งใช้ล่าสุดเสมอ จึงแย่งแท็บได้ทุกครั้งที่ China เริ่มงาน รวมถึงงานตั้งเวลา
- **บัญชี Flow:** China เลือกบัญชีจากแท็บที่ผู้ใช้โฟกัสล่าสุด และจำว่าบัญชีไหนโควตาหมดไว้ในพื้นที่เก็บของตัวเองเท่านั้น
- **TikTok:** ตรวจเพียงว่าชื่อผู้ใช้ที่ล็อกอินตรงกับที่ตั้งไว้ ไม่สลับบัญชีให้

**ผู้ใช้ตัดสิน:** ผลิตพร้อมกับ China ได้ เพราะใช้บัญชีแยกกันอยู่แล้ว

**วิธีทำให้พร้อมกันได้จริง (ผู้ออกแบบเป็นผู้เลือก):** ติดตั้งผี 1 บาทใน **Chrome profile ของบัญชีผี 1 บาทเอง** แยกจาก profile ที่ลง China
- ส่วนขยายมองเห็นเฉพาะแท็บใน profile ของตัวเอง China จึงแย่งแท็บ ChatGPT/Flow/TikTok ของผี 1 บาทไม่ได้เลย โดยไม่ต้องแก้ China
- bridge แยกพอร์ต (8786 / 8787) และตัวเชื่อม Chrome แยกชื่อ จึงรันพร้อมกันได้
- ถ้าใช้ profile เดียวกันแต่สลับบัญชี Google จะยังแย่งแท็บ Flow กันได้ ให้ README และหน้าแรกของตัวติดตั้งบอกขั้นตอนสร้าง profile แยก
- ผี 1 บาทใช้เฉพาะแท็บที่ตัวเองเปิดและบันทึกไว้ (ตัด fallback "แท็บไหนก็ได้") เพื่อไม่ไปหยิบแท็บที่ผู้ใช้เปิดเอง
- เสียงพากย์ในเครื่อง (GPU) อาจช้าลงเมื่อสองแอปพากย์พร้อมกัน ยอมรับได้ ไม่ต้องทำคิวร่วม

### 5.3 เนื้อหา — Blueprint ผี 1 บาท

เขียน `extension/VDO Concept.txt` ใหม่เป็น "V1 ผี 1 บาท" ส่งไปให้ ChatGPT ทั้งฉบับทุกครั้งเหมือนเดิม
- **ต้องคงรูปแบบที่โค้ดอ่าน:** STAGE 1 (ตารางหัวข้อ), OUTPUT 2 (บทพากย์ล้วน), OUTPUT 5 (5.1 Style Bible · 5.2 Character Bible · 5.3 Shot List), OUTPUT 4 (ภาพปก), ชื่อไฟล์ = timecode และแท็กตัวละคร `@TAG` ส่วนที่เปลี่ยนคือกติกาเนื้อหาข้างใน
- **ความยาว:** ตั้งต้น 1 นาที (ช่องความยาวในแผงข้างยังแก้ได้) ใช้สูตรนับความยาวเดิมของ China
- **โครงเรื่อง 1 นาที:** 0–5 วิ เปิดด้วยภาพหรือประโยคที่ทำให้สะดุ้ง → ตั้งเรื่อง (ใคร ที่ไหน ทำอะไรผิด) → เหตุประหลาด → เผชิญหน้าผี → หักมุมหรือผลกรรม → ประโยคปิดสอนใจแบบเล่มละบาท ("ทำกรรมใดไว้ ย่อมได้รับผลนั้น") ต้องจบในคลิปเสมอ ภาพละ 2–3 วินาที รวมประมาณ 20–25 ภาพ
- **5 หมวดเนื้อหา** ครอบคลุมแนวที่การ์ตูนเล่มละบาทเคยมีจริง ผู้ใช้ขอให้มีหมวดนอกจากเรื่องผี ส่วนรายการหมวดผู้ออกแบบเป็นผู้เลือก
  - ชื่อแอปยังเป็น "ผี 1 บาท" และผีเป็นหมวดหลัก
  - แต่ละหมวดมีชุดสีของตัวเองตามระบบ category-themes เดิม มีตัวเลือก "คละหมวด" และจำค่าที่เลือกไว้
  1. **ผีไทย (หมวดหลัก):** แบ่งเป็น 3 มุม ผีพื้นบ้าน (กระสือ ปอบ กระหัง ผีพราย นางตานี นางตะเคียน ผีโพง ผีตายทั้งกลม) · ผีกรรมตามสนอง (ชู้ ฆ่า โลภ แล้วผีกลับมาทวง) · ผีเรื่องเล่าร่วมสมัย (ถนนเปลี่ยว หอพัก โรงพยาบาลเก่า บ้านร้าง)
  2. **ไสยศาสตร์ & หมอผี:** คุณไสย ของขลัง ตะกรุด หมอผีปราบผี พระธุดงค์เจอของเฮี้ยน
  3. **นิทานพื้นบ้าน & จักรๆ วงศ์ๆ:** ยักษ์ นางฟ้า เจ้าชายตกยาก ของวิเศษ ใช้นิทานที่หมดลิขสิทธิ์แล้ว (เช่น สังข์ทอง ปลาบู่ทอง ไกรทอง) หรือแต่งใหม่ ฉากสู้ไม่มีเลือด
  4. **ชีวิตสอนใจ (ดราม่าเล่มละบาท):** ลูกอกตัญญู เมียหลวงเมียน้อย คนจนคนรวย เป็นกรรมตามสนองแบบไม่มีผี
  5. **ตลกบ้านทุ่ง:** มุกตลกหักมุมแบบการ์ตูนตลกเล่มละบาท จบด้วยมุกปิดแทนประโยคสอนใจ
  - **โครงเรื่อง 1 นาทีใช้ร่วมกันทุกหมวด:** เปิดให้สะดุ้งหรือสงสัย → เรื่อง → หักมุม → ประโยคปิด เรื่องต้องจบในคลิปเสมอ
- **ตัดออก:** การดึงประวัติและภาพบุคคลจริง 52 คนจากวิกิพีเดีย (`00_ref` แบบบุคคล), กติกาคละวรรณกรรมจีน และกติกาเรื่องลิขสิทธิ์นิยายจีน
- **กติกาใหม่:** ผีและตัวละครเป็นเรื่องแต่ง ไม่ระบุตัวบุคคลจริง ไม่อ้างสถานที่จริงที่ระบุได้ (เช่น ชื่อโรงพยาบาลจริง) ไม่ลบหลู่ศาสนา และไม่ลอกเรื่องที่มีลิขสิทธิ์ (หนังหรือละครผีดัง)
- **กันเรื่องซ้ำ:** ใช้ `dedupe.js` เดิม โดยให้ตัวตัดสินดูจาก "หมวด + ชนิดผีหรือตัวละครหลัก + พล็อตหลัก"
- **ระดับความสยอง** (ผู้ออกแบบเป็นผู้เลือก — ผู้ใช้แก้ได้)
  - ห้ามเปลือย ห้ามเรื่องเพศ แม้เล่มละบาทต้นฉบับจะมี
  - ให้สยองด้วยหน้าผี (ตาโปน ฟันแหลม ผมกระเซิง) เงา และบรรยากาศ เลือดมีได้เล็กน้อย เช่น หยดที่มุมปาก หรือรอยจาง ๆ
  - ห้ามไส้ ศพแหลก หรือบาดแผลชัด
  - กระสือวาดเป็นหัวลอย ผมยาว มีแสงเรืองใต้คอแทนอวัยวะ
  - ไม่ใช้เด็กเป็นเหยื่อ

### 5.4 ลายเส้น (หัวใจของงาน)

ใน `extension/prompts.js` ให้แทน `ART_STYLES` (doodle / inkwash) ด้วยลายเส้นเดียวคือ **`lemlabaht`** ซึ่งเป็นค่าตั้งต้นและไม่มีตัวเลือกอื่น คงรูปแบบ `rule` / `flow` / `body` เดิมไว้ และให้คลิปเก่าที่เป็น doodle/inkwash ถูกอ่านเป็น lemlabaht

**สิ่งที่เห็นจากเล่มจริง** (ภาพ 37 ภาพใน `references/onebaht/` ส่วนใหญ่เป็นสำนักพิมพ์นครไทยยุค 2520 อีกส่วนเป็นรวมเล่มการ์ตูนผี "กระสือ...กินคน")
- **ปก**
  - วาดเส้นหมึกดำ แล้วลงสีไม้หรือสีน้ำสีสด ได้แก่ เหลือง ชมพู ฟ้า เขียว แดง และพื้นหลังมักเป็นเหลืองหรือฟ้าอ่อน
  - ตัวละครครึ่งตัวขนาดใหญ่อยู่หน้า มีฉากเล็กอยู่ด้านหลัง
  - ชื่อเรื่องตัวหนาสีแดง ม่วง หรือเขียว มีลูกโป่งคำพูดเขียนมืออยู่บนปก และมีลายเซ็นนักวาด
  - โลโก้สำนักพิมพ์อยู่มุมซ้ายบน ขอบบนมีแถบลายเฉียงแดง–น้ำเงิน และป้าย "1 บาท" อยู่มุมขวาล่าง
  - ปกเรื่องผีโทนมืดกว่าเล่มอื่น ใช้แดงเลือดกับเขียวป่า
  - ปกหลังเป็นโฆษณาสินค้า
- **หน้าใน**
  - หมึกดำบนกระดาษปรู๊ฟเหลืองนวล หน้าละ 4–6 ช่อง (2 คอลัมน์ × 2–3 แถว)
  - กล่องคำบรรยายสี่เหลี่ยมอยู่มุมบนของช่อง ตัวหนังสือลายมือแน่นมาก
  - มีลูกโป่งคำพูดเขียนมือ และคำเสียงประกอบตัวหนา เช่น "โป๊ก"
  - ลงดำทึบเยอะ แรเงาด้วยเส้นขนาน
  - ผีหน้ากะโหลก ตาโปน ฟันเรียงเห็นชัด
- **หน้าแรกของเรื่องและบางหน้าใน พิมพ์ด้วยหมึกสีเดียว (spot color)** เช่น น้ำเงิน เขียวหัวเป็ด หรือม่วง แทนสีดำ เป็นการพิมพ์สองสีสลับหน้า หน้าแรกมีชื่อเรื่องลายมือตัวใหญ่กับภาพใหญ่หนึ่งภาพ
- **ผู้ใช้ตัดสิน: ทุกภาพต้องเป็นภาพสี** ทั้งภาพในเรื่อง ภาพปก Style Kit และภาพธีมของแอป ไม่มีภาพขาวดำหรือภาพหมึกสีเดียว
- **ภาพในเรื่อง (ฉากการ์ตูนเต็มเฟรม):** ใช้ลายเส้นแบบหน้าในของเล่มจริง แล้วลงสีแบบปกเล่มจริง
  - **เส้น:** หมึกดำ ลงดำทึบที่ผมและเงา แรเงาด้วยเส้นขนาน หน้าคนและเสื้อผ้าใช้เส้นปากกาบาง ผีใช้เส้นแรเงาไขว้ถี่ ๆ ผมกระเซิงฟุ้ง
  - **สี:** ลงสีไม้/สีน้ำสีสดทับเส้นหมึก เห็นรอยสีและเนื้อกระดาษ ใช้ชุดสีปกเล่มละบาท (เหลือง ชมพู ฟ้า เขียว แดง) ไม่ใช่สีไล่เฉดแบบดิจิทัล ไม่ใช่สีเรียบแบบอนิเมะ
  - **ชุดสีตามหมวด (ผู้ออกแบบเป็นผู้เลือก):** ผีและไสยศาสตร์ใช้โทนมืด แดงเลือด เขียวป่า ม่วงกลางคืน ตามปกผีจริง ส่วนนิทาน ดราม่า และตลกใช้โทนสว่าง พื้นเหลืองหรือฟ้าอ่อน ตามปกนครไทย
  - ตัวละครมีสัดส่วนสมจริงแบบการ์ตูนไทยยุค 2520 ผมทรงหนังไทยเก่า หน้าตาจริงจัง
  - ฉากเป็นเรือนไทยใต้ถุนสูง ป่าไผ่ ต้นตะเคียน ศาลา วัดร้าง ทุ่งนายามค่ำ
  - ภาพ Flow หนึ่งภาพเป็นหนึ่งฉากเต็มเฟรม ไม่มีกรอบช่อง ไม่มีขอบกระดาษ (ผู้ใช้ตัดสิน: เล่าแบบการ์ตูน ไม่เอากรอบช่อง)
  - ไม่ใช่อนิเมะ ไม่ใช่มังงะ ไม่ใช่ 3D ไม่ใช่ doodle
  - **ไม่มีตัวหนังสือในภาพ** (ซับไตเติลมาจาก ffmpeg) เพราะ Flow เขียนอักษรไทยได้ไม่ดี
- **ภาพปก (OUTPUT 4):** ทำแบบปกเล่มละบาท
  - วาดเส้นหมึกดำแล้วลงสีไม้หรือสีน้ำสีสด ตามแบบปกจริงที่บรรยายไว้ข้างบน ผีหรือตัวละครหลักครึ่งตัวใหญ่ด้านหน้า มีฉากเล็กอยู่ด้านหลัง
  - แถบลายเฉียงแดง–น้ำเงินที่ขอบบน
  - โลโก้ต้องเป็นของเราเองคือ "ผี 1 บาท" ห้ามเลียนโลโก้ของสำนักพิมพ์จริง (เช่น "N" ของนครไทย)
  - ชื่อเรื่องตัวแดงใหญ่ โลโก้ "ผี 1 บาท" มุมซ้ายบน และป้าย "1 บาท" มุมขวาล่าง
  - ภาพปกเป็นภาพเดียวที่อนุญาตให้มีตัวหนังสือ
**ผู้ใช้ต้องการ:** ลายเส้นและสีเหมือนการ์ตูนเล่มละบาทจริงมากที่สุด จึงทำ 3 ชั้นซ้อนกัน เพราะคำบรรยายอย่างเดียวไม่พอ

**ชั้น 1 — ชุดอ้างอิงลายเส้นของเราเอง (Style Kit)**
- **ผู้ใช้ตัดสิน (แนวทาง ก):** ใช้ภาพการ์ตูนเล่มละบาทจริงเป็นแบบเฉพาะตอนสร้าง Style Kit ครั้งเดียว ไม่ส่งภาพจริงไปกับแอป
  - แนวทาง ข (ให้ Flow ใช้ภาพจริงทุกช็อต) ถูกตัด เพราะต้องแจกภาพสแกนผลงานของนักวาดที่ยังทำงานอยู่ไปกับ Setup.exe
  - แนวทาง ค (ขออนุญาตหรือจ้างนักวาดตัวจริงวาด Style Kit) ทำทีหลังได้เพื่ออัปเกรด
- **คลังภาพจริง `references/`**
  - เก็บหน้าในและปกเล่มละบาทจริง 20–30 ภาพ พร้อมจดที่มาใน `references/SOURCES.md`
  - ใช้ในเครื่องเจ้าของเท่านั้น ห้ามขึ้น repo public และห้ามใส่ใน Setup.exe (เพิ่ม `references/` ใน `.gitignore` และในการตรวจก่อนสร้างตัวติดตั้ง)
- **สร้าง Style Kit**
  - จำนวน 6–8 ภาพ เป็นภาพสีทั้งหมด: ฉากการ์ตูนลงสีเต็มเฟรม (ผี, ผู้หญิง, ผู้ชาย, ฉากเรือนไทย, ป่ายามค่ำ), ปก 1–2 ภาพ และแถบชุดสีของแต่ละหมวด
  - อัปโหลดภาพจริงจาก `references/` ให้ ChatGPT web ในบัญชีของผู้ใช้ แล้วสั่งวาดภาพใหม่ด้วยเทคนิคเดียวกัน (เส้น การแรเงา สีกระดาษ ชุดสีปก) แต่ตัวละคร ฉาก และองค์ประกอบต้องเป็นของใหม่ ห้ามลอกช่องหรือตัวละครจากภาพจริง
  - วางเทียบกับภาพจริงแล้วปรับซ้ำจนผู้ใช้บอกว่าเหมือน
  - เก็บไว้ที่ `extension/style-kit/` ซึ่งเป็นงานของเราเอง ส่งไปกับแอปได้ และต้องจดที่มาของทุกภาพ
- **การใช้งาน**
  - ทุกช็อตใน Flow แนบภาพจาก Style Kit 1–2 ภาพเป็น ingredient คู่กับภาพตัวละคร (Flow agent ของ China แนบภาพได้อยู่แล้วผ่าน `attachImages`)
  - Style Bible ใน ChatGPT อ้างชุดนี้ด้วย

**ชั้น 2 — กติกาลายเส้นเป็นตัวหนังสือ** ตามรายการด้านบน (`lemlabaht` rule/flow/body)

**ชั้น 3 — แปลงภาพให้เป็นงานพิมพ์ (inkify)**
- ทำในเครื่องหลังโหลดภาพจาก Flow และก่อนตัดต่อ ใช้โค้ดล้วน ไม่ใช้ AI ผลลัพธ์จึงคงที่ทุกครั้ง
- ทุกภาพผ่านขั้นตอนเดียวกัน (ภาพสีทั้งหมด)
  - ทำเส้นหมึกให้ดำสนิทและคม
  - ลดสีให้อยู่ในชุดสีของหมวด
  - วางบนพื้นผิวกระดาษเหลืองนวลที่เราสร้างเอง ใส่หมึกซึมเล็กน้อยและเกรนกระดาษ
  - ทำให้สีเหลื่อมกันเล็กน้อย 1–2px และมีเม็ดสกรีนจาง ๆ แบบงานพิมพ์ออฟเซ็ตราคาถูก
- ปิดทีละคลิปได้ ส่วนเครื่องมือที่ใช้ (Python/Pillow หรือ ffmpeg) ให้ผู้สร้างเลือก แต่ต้องใช้ได้ในเครื่องลูกค้าที่ลงจาก Setup.exe

**สี:** ทุกภาพเป็นภาพสี ไม่มีตัวเลือกขาวดำ (ผู้ใช้ตัดสิน) ชุดสีเปลี่ยนตามหมวด

**การนำเสนอในคลิป: เล่าแบบการ์ตูน (ผู้ใช้ตัดสิน 22 พ.ย. — ไม่เอากรอบช่อง)**
- ทุกช็อตเป็นภาพการ์ตูนเต็มจอ (full-bleed) เล่าต่อกันเหมือนการ์ตูนเล่าเรื่อง ไม่มีกรอบช่อง ไม่มีพื้นกระดาษรอบภาพ ไม่มีเลขหน้า
- ซับไตเติลเป็น "กล่องคำบรรยาย" สีกระดาษเหลืองพร้อมตัวอักษรไทยแบบลายมือ ใช้ฟอนต์สัญญาอนุญาต OFL ที่ฝังมากับแอป (กฎห้ามฟอนต์ภายนอกใช้กับหน้าจอส่วนขยาย ไม่เกี่ยวกับซับในวิดีโอ)
- ภาพแรกเป็นแบบปกเล่ม เพื่อใช้เป็นภาพตัวอย่างคลิปบน TikTok ด้วย

**ยอมรับเมื่อ**
- ผู้ใช้อนุมัติ Style Kit โดยวางเทียบกับ `references/destudio_1.jpg` และ `momentum_2.jpg`
- ผู้ใช้อนุมัติช็อตตัวอย่าง 3 ภาพหลังผ่าน inkify แล้ว ได้แก่ ผี, คนในเรือนไทย และปก
- ปรับปรุง `scripts/test-art-style.mjs` ให้ตรวจกติกาใหม่

### 5.5 ธีมหน้าตา (สั่งทำใน ChatGPT web แล้วดึงมา)

- **โลกของธีม:** โรงพิมพ์การ์ตูนผียุค 2520 ยามดึก ใช้กระดาษปรู๊ฟเหลืองหม่น หมึกดำ และแดงชื่อเรื่องแบบปกเล่มละบาท
  - คงกฎผู้ใช้จาก China: โทนมืดนวลตา ไม่มีพื้นขาว และโหมดสว่างคือโรงพิมพ์ตอนกลางวันที่สว่างกว่าโหมดมืดเพียงเล็กน้อย
  - คงกฎอื่นจาก China ทั้งหมด: ภาษาไทย ไม่ใช้ framework หรือฟอนต์ภายนอก แผงกว้าง 360–450px ภาพเคลื่อนไหวใช้ CSS เบา ๆ เคารพ reduced-motion ถามสถานะทุก 3 วินาที และไม่ถามเมื่อ hidden
- **ตัวละคร 5 แผนก:** เป็นผู้ใหญ่ วาดด้วยลายเส้นเล่มละบาทแบบลงสีเต็ม (ไม่ใช่ 3D ไม่ใช่ขาวดำ) แต่ละคนมี atlas โปร่งใส 4×3 จำนวน 12 เฟรม สเปกเดียวกับ `docs/design/adult-atlas-*-prompt.txt` ของ China และแต่ละแผนกมีสีประจำตัว
  - **เขียนบท (ChatGPT):** นักเขียนเรื่องผีสูงวัยนั่งหน้าเครื่องพิมพ์ดีด
  - **วาดภาพ (Flow):** นักวาดการ์ตูนเล่มละบาทกำลังจุ่มปากกาหมึก
  - **แอนิเมชัน (Kie):** คนฉายหนังกลางแปลงกำลังหมุนม้วนฟิล์ม
  - **เสียงพากย์:** นักพากย์หนังกลางแปลงหรือนักเล่าเรื่องผีทางวิทยุ
  - **ตัดต่อ:** ช่างโรงพิมพ์กำลังเย็บเล่ม
- **ไอคอนแอป:** ปกการ์ตูนจิ๋ว "ผี 1 บาท" มีหน้าผีกระสือ ตัวหนังสือแดง และเหรียญ 1 บาท ใช้ภาพเดียวกันทุกที่ (ส่วนขยาย, หมวด, แจ้งเตือน, .ico, ทางลัด)
- **ฉากพื้นหลัง:** `world-day` / `world-night`
- **ขั้นตอนการทำ**
  1. เขียน prompt ไว้ที่ `docs/design/phi-*.prompt.txt`
  2. Claude สั่งสร้างภาพใน ChatGPT web ผ่าน Chrome ของผู้ใช้ (ผู้ใช้ล็อกอินไว้แล้ว) แล้วดาวน์โหลดลง `assets/phi-raw/`
  3. รัน `python scripts/build-icons.py` แล้วตามด้วย `scripts/build-sprite-registration.py`
  4. ภาพที่ใช้จริงทุกภาพต้องมีที่มาจดไว้ (ใช้ prompt ไหน สร้างเมื่อไร)

### 5.6 เสียงและการตัดต่อ

- **เสียง:** ใช้ทุกเอนจินเดิม แต่เปลี่ยนน้ำเสียงตั้งต้นเป็นผู้ชายเสียงทุ้ม เล่าช้า ๆ ชวนขนลุก ใช้ tag น้ำเสียงของ ElevenLabs / คำสั่งน้ำเสียงของ Gemini / Edge ที่ช้าลงและทุ้มลง

### 5.8 ฟีเจอร์ของผี 1 บาท (คิดใหม่)

ผู้ใช้ขอให้คิดฟีเจอร์ใหม่ให้เหมาะกับแอป รายการนี้ผู้ออกแบบเป็นผู้เลือก

**ตัดออก** (เอาออกให้ครบทั้งหน้าจอ โค้ด prompt และทดสอบ ไม่ใช่แค่ซ่อนปุ่ม)
- โหมดเล่าประวัติศาสตร์ / นิยาย
- ภาษาจีน
- หมวด "ผู้เล่าเรื่อง (ตัวเราเอง)" (`self_narrator.mjs` / `self_monk.mjs`)
- การดึงบุคคลจริงจากวิกิพีเดีย

**เปลี่ยนให้เข้ากับแอป**
- อารมณ์ "เพิ่มความสุข" → **ระดับความสยอง เบา / กลาง / เข้ม** ใช้กับหมวดผีและไสยศาสตร์ ระดับ "เข้ม" ยังต้องอยู่ในกติกาข้อ 5.3
- "ไขปริศนาจีน" (`riddle.mjs`) → **"ทายสิ ผีอะไร?"** เป็นภาพเงาผีให้ทายสำหรับ Facebook Story ใช้ระบบโพสต์ Story เดิม

**เพิ่มใหม่**
- **ปกเล่มละบาทอัตโนมัติ + "เล่มที่ N":** เลขเล่มนับต่อเนื่องทุกคลิป ใช้เป็นภาพปกคลิปและภาพตัวอย่าง
- **ชุดสีตามหมวด, Style Kit, inkify และกล่องคำบรรยายแบบการ์ตูน** (ข้อ 5.4)

**คงไว้**
- ภาษาไทย (หลัก) และภาษาอังกฤษ
- ตัวเขียนบท Gemini
- ฟีเจอร์ในข้อ 5.7 ทั้งหมด

## 6. แอปแยกและชุดติดตั้งสำหรับลูกค้า (ผู้ใช้ตัดสิน 22 พ.ย.)

- **ผี 1 บาทเป็นแอปแยกอิสระ** China เป็นเพียงแบบอย่างในการเขียน ไม่มีส่วนใดของผี 1 บาทที่ต้องพึ่ง China ตอนใช้งาน
- **ทำเป็นชุดติดตั้ง (Setup.exe) ให้ลูกค้า**
  - ใช้ระบบสร้างตัวติดตั้งของ China (`scripts/build-installer.mjs`, Inno Setup) แต่เปลี่ยนตัวตนทั้งหมด
  - ไฟล์ที่ได้: `dist/Phi1Baht-Setup-<version>.exe`
  - คงการตรวจก่อนสร้างทุกครั้ง: ห้ามมี API key, เสียงที่โคลน และงานคลิปของเจ้าของติดไปกับตัวติดตั้ง
- **ตัวอัปเดตในแอป**
  - ตัวอัปเดตโหลดโค้ดจาก `codeload.github.com` โดยไม่ล็อกอิน จึงต้องใช้ **GitHub repo ใหม่ที่เป็น public** (ชื่อที่เสนอ: `romeofiles007-arch/phi1baht`)
  - ต้องเปลี่ยน `package.json` `repository`, ไฟล์ VERSION และ `scripts/build-package.mjs` ให้ชี้ไป repo ใหม่ ห้ามชี้ไป repo ของ China
  - เนื่องจาก repo เป็น public ต้องตรวจ `.gitignore` ให้กัน `.env`, ค่าตั้งเครื่อง และงานของผู้ใช้ก่อน push ครั้งแรก
  - **การสร้าง repo และการ push ครั้งแรกเป็นงานที่เผยแพร่ออกภายนอก ต้องถามผู้ใช้ก่อนทำตอนถึงขั้นนั้น**
