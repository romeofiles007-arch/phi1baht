# ผี 1 บาท Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** สร้างแอป "ผี 1 บาท" (ส่วนขยาย Chrome MV3 + โปรแกรม Node ในเครื่อง + Setup.exe) ที่ผลิตคลิปการ์ตูนไทยเล่มละบาทลงสี ยาว 1 นาทีอัตโนมัติ โดยก๊อปโค้ดจาก `E:\China` แล้วเปลี่ยนตัวตน เนื้อหา ลายเส้น และธีม

**Architecture:** ก๊อปไฟล์ที่ git ติดตามของ `E:\China` มาที่ `E:\การ์ตูนไทย๑บาท` แล้วเริ่ม git ใหม่ จากนั้นแก้เป็นชั้น: ตัวตน (พอร์ต/host/key) → ตัดฟีเจอร์จีน → เนื้อหา 5 หมวด → ลายเส้น `lemlabaht` + Style Kit + inkify → การนำเสนอในคลิป → ธีม UI → ตัวติดตั้ง/อัปเดต ทุกขั้นคงสถาปัตยกรรมเดิม (แผงข้าง ↔ bridge 127.0.0.1 ↔ pipeline 1–6)

**Tech Stack:** Node 24 (ESM, ไม่มี dependency ภายนอก), ffmpeg 8 (ประมวลผลภาพ/ตัดต่อ), Chrome MV3, Inno Setup 6, Python 3.14 + Pillow (เฉพาะ `scripts/build-icons.py`), ทดสอบด้วย `node --test` / สคริปต์ `scripts/test-*.mjs`

**Spec:** `docs/superpowers/specs/2026-11-22-phi-1-baht-design.md` (อ่านทั้งฉบับก่อนเริ่มทุกงาน)

## Global Constraints

- ห้ามแก้ไฟล์ใดใน `E:\China` — ทุกงานจบด้วย `git -C E:/China status --short` ว่างเหมือนก่อนเริ่ม
- ห้ามอ่านหรือเปิดเผย `.env`, `config/project.config.json`, `settings_local.json`
- พอร์ต bridge `8787` · native host `com.phi1baht.bridge` · โฟลเดอร์ติดตั้ง `{userpf}\Phi1Baht` · junction `%LOCALAPPDATA%\Phi1Baht\app` · ไฟล์ติดตั้ง `dist/Phi1Baht-Setup-<version>.exe`
- ชื่อที่ผู้ใช้เห็น: `ผี 1 บาท` ทุกที่ ห้ามมีคำ `จีน|ตำนานจีน|China|ธรรมะ|dhamma` ในไฟล์ที่ส่งให้ลูกค้า (ยกเว้น `docs/`)
- หน้าจอเป็นภาษาไทย · แผงข้าง 360–450px โทนมืดนวลตา ไม่มีพื้นขาว · ไม่ใช้ framework/ฟอนต์ภายนอกในส่วนขยาย · motion เฉพาะ CSS เคารพ reduced-motion · polling 3 วินาที ไม่ poll ตอน `document.hidden`
- ความยาวคลิปตั้งต้น 1 นาที · แนวตั้ง 9:16 (1080×1920) ตั้งต้น
- **ทุกภาพเป็นภาพสี** (ภาพในเรื่อง ปก Style Kit ภาพธีม) — ไม่มีขาวดำ ไม่มีหมึกสีเดียว
- ภาพในเรื่องไม่มีตัวหนังสือ ยกเว้นภาพปก
- ห้ามเปลือย/เรื่องเพศ · ห้ามไส้ ศพแหลก บาดแผลชัด · เลือดได้เล็กน้อย · ไม่ใช้เด็กเป็นเหยื่อ
- `references/` ห้ามขึ้น git, ห้ามใส่ใน Setup.exe, ห้ามแนบให้ Flow ตอนผลิต
- การสร้าง GitHub repo / push / โพสต์จริง ต้องถามผู้ใช้ก่อนทุกครั้ง
