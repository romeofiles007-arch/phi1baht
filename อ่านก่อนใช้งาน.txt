ผี 1 บาท — ทำคลิปการ์ตูนผีเล่มละบาท 1 นาที อัตโนมัติ

สิ่งที่ต้องมี: Windows 10/11 · Google Chrome
(ไม่ต้องติดตั้ง Node.js / ffmpeg / Python — แถมมาในโปรแกรมแล้ว)

วิธีติดตั้ง (ครั้งเดียว)
  1. ดับเบิลคลิก Phi1Baht-Setup-<รุ่น>.exe แล้วกด ถัดไป → ติดตั้ง
     (ถ้าได้เป็นโฟลเดอร์แทน: ดับเบิลคลิก ติดตั้งครั้งแรก.bat)
  2. ทำตามหน้าจบใน Chrome: เปิด chrome://extensions → เปิด Developer mode
     → Load unpacked → วางที่อยู่โฟลเดอร์ที่คัดลอกไว้ให้ (Ctrl+V) → ปักหมุดไอคอน ผี 1 บาท
  3. สำคัญ: ทำข้อ 2 ใน Chrome profile ของบัญชีผี 1 บาท (แยกจากแอปอื่น)
     จะได้ใช้พร้อมแอปอื่นได้โดยแท็บ ChatGPT/Flow ไม่ชนกัน
  4. ใน profile เดียวกันนั้น ล็อกอิน ChatGPT และ Google Flow (จำเป็น)
     · TikTok / Facebook (ถ้าจะโพสต์)
  5. กดไอคอน ผี 1 บาท บนแถบ Chrome — โปรแกรมเปิดเอง

วิธีใช้
  เลือก "หมวดคลิป" (ผีไทย · ไสยศาสตร์ · นิทาน · ชีวิตสอนใจ · ตลกบ้านทุ่ง หรือ คละหมวด)
  เลือกระดับความสยอง เบา/กลาง/เข้ม ที่ ⚡ ตั้งค่าคลิป แล้วกดสร้าง — ได้ไฟล์ MP4 ในโฟลเดอร์ projects
  ภาพออกมาเป็นการ์ตูนสีสด ไม่ออกเหลือง · กด ⏹ หยุดได้ทุกเมื่อ

เพลงประกอบ
  โปรแกรมไม่แถมเพลง — ใส่ไฟล์ mp3 ของคุณเอง (ที่มีสิทธิ์ใช้) ลงในโฟลเดอร์ music
  (สร้างโฟลเดอร์ชื่อ music ในโฟลเดอร์โปรแกรมถ้ายังไม่มี) ถ้าไม่มี คลิปจะไม่มีเพลง

ค่าใช้จ่าย
  เสียงพากย์ตั้งต้นใช้ Edge ฟรี · ภาพเคลื่อนไหวจาก Kie ปิดไว้ — ถ้าเปิดเองจะคิดเครดิตของ Kie ตามจำนวนฉาก

ย้ายโฟลเดอร์ทีหลัง → ดับเบิลคลิก ติดตั้งครั้งแรก.bat อีกครั้ง
อัปเดต → โปรแกรมตรวจเองทุก 30 นาที มีรุ่นใหม่จะขึ้นแถบ "มีอัปเดตใหม่" ในแผงข้าง กด "อัปเดต"
         (การตั้งค่า งานคลิป และเสียงที่ทำไว้ไม่หาย · อัปเดตได้เมื่อไม่ได้ทำคลิปอยู่)
ถอนการติดตั้ง → Settings → Apps → ผี 1 บาท (หรือ ถอนการติดตั้ง.bat ถ้าได้เป็นโฟลเดอร์)
         extension ใน Chrome ต้องกด Remove เอง
