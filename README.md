# ผี 1 บาท — คลิปการ์ตูนผีเล่มละบาท 1 นาที ทำอัตโนมัติ

ระบบทำคลิปการ์ตูนไทยสไตล์ "เล่มละบาท" ยาว 1 นาที แนวตั้ง 9:16 สำหรับ TikTok / Reels ตั้งแต่ได้หัวข้อ เขียนบท พากย์เสียง วาดภาพ ตัดต่อ จนได้ไฟล์ MP4
ประกอบด้วย 2 ส่วน: ส่วนขยาย Chrome (แผงข้าง) และตัวเชื่อมในเครื่อง (bridge ที่ `127.0.0.1:8787`, ตัวเชื่อม Chrome ชื่อ `com.phi1baht.bridge`)

- **ChatGPT** เขียนบทและกำกับภาพ · **Google Flow** วาดภาพ · เสียงพากย์และตัดต่อทำในเครื่อง
- ผี 1 บาทเป็นแอปแยกอิสระ ไม่ต้องใช้โปรแกรมอื่นประกอบ

## สำหรับลูกค้า — ติดตั้งด้วย Setup.exe

1. ดับเบิลคลิก `Phi1Baht-Setup-<รุ่น>.exe` → ถัดไป → ติดตั้ง (ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ) ได้ครบทุกอย่าง: โปรแกรม + Node + ffmpeg + เสียง Edge ไม่ต้องลงอะไรเพิ่ม
2. หน้าสุดท้ายของตัวติดตั้งบอกขั้นตอนใน Chrome (ทำครั้งเดียว — Chrome ไม่ให้โปรแกรมทำแทน): เปิด `chrome://extensions` → เปิด "Developer mode" → "Load unpacked" → วางที่อยู่โฟลเดอร์ที่คัดลอกไว้ให้ → ปักหมุดไอคอน "ผี 1 บาท"
3. **ทำขั้นตอนข้อ 2 ใน Chrome profile ของบัญชีผี 1 บาท** (ดูหัวข้อ Chrome profile ด้านล่าง)
4. ล็อกอินเว็บที่ต้องใช้ใน profile นั้น แล้วกดไอคอนผี 1 บาท — โปรแกรมเปิดเอง

ติดตั้งผิดที่/ย้ายโฟลเดอร์: เปิด "ตั้งค่า Chrome extension อีกครั้ง" จากเมนู Start
ถอนการติดตั้ง: Settings → Apps → ผี 1 บาท (งานคลิปและ `.env` ที่เป็น API key ของลูกค้าจะเก็บไว้ ไม่ถูกลบ)

## สำหรับเจ้าของ — ติดตั้งจากซอร์ส

ต้องมี Windows 10/11, Google Chrome, Node.js 20+, ffmpeg + ffprobe ใน PATH

```
git clone https://github.com/romeofiles007-arch/phi1baht
cd phi1baht
npm install
ติดตั้งครั้งแรก.bat        # ลงทะเบียนตัวเชื่อม Chrome (com.phi1baht.bridge) + ตรวจเครื่อง
```

จากนั้น Load unpacked โฟลเดอร์ `extension/` ใน Chrome (profile ผี 1 บาท) แล้วกดไอคอน
ทดสอบ: `node --test scripts/test-identity.mjs` และไฟล์ `scripts/test-*.mjs` อื่นๆ ด้วย `node --test <ไฟล์>`

สร้างชุดติดตั้งให้ลูกค้า:

```
node scripts/build-installer.mjs     # ได้ dist/Phi1Baht-Setup-<รุ่น>.exe
```

ต้องมี Inno Setup 6, ffmpeg ใน PATH และ `tts/.venv-edge` (Python 3.10 + edge-tts) — สคริปต์ตรวจก่อนสร้างทุกครั้งว่าไม่มี API key, เสียงที่โคลน, งานคลิป หรือภาพอ้างอิงลิขสิทธิ์ (`references/`) ติดไปกับตัวติดตั้ง

## Chrome profile — ลงส่วนขยายใน profile ของบัญชีผี 1 บาท

ส่วนขยายมองเห็นเฉพาะแท็บใน Chrome profile ของตัวเอง ดังนั้น:

- สร้าง/ใช้ **Chrome profile แยกสำหรับบัญชีผี 1 บาท** (ไอคอนโปรไฟล์มุมขวาบน → Add) ล็อกอิน ChatGPT, Google Flow (และ TikTok/Facebook ถ้าจะโพสต์) ด้วยบัญชีของผี 1 บาทใน profile นั้น แล้ว Load unpacked ที่ profile นั้น
- เมื่อแยก profile แล้ว **ใช้พร้อมกับแอปทำคลิปตัวอื่นได้** โดยแท็บ ChatGPT/Flow ไม่ชนกัน (ตัวเชื่อมแยกชื่อ พอร์ตแยก 8787)
- ถ้าใช้ profile เดียวกับแอปอื่นแล้วสลับบัญชี Google ไปมา แท็บ Flow อาจถูกแย่งกัน
- ผี 1 บาทใช้เฉพาะแท็บที่ตัวเองเปิดไว้ ไม่หยิบแท็บที่คุณเปิดเองมาใช้
- เสียงพากย์ในเครื่อง (ใช้การ์ดจอ) อาจช้าลงถ้าสองแอปพากย์พร้อมกัน

## ใช้งาน

เปิดแผงข้างแล้วเลือก **หมวดคลิป** (หรือ "คละหมวด") กดสร้าง ระบบทำต่อเองจนได้ MP4 ในโฟลเดอร์ `projects/` ปุ่ม ⏹ หยุดทุกอย่างได้ตลอด ตั้งค่าคลิปที่ ⚡ ตั้งค่าคลิป

### 5 หมวด

1. **ผีไทย** (หมวดหลัก) — ผีพื้นบ้าน · ผีกรรมตามสนอง · ผีเรื่องเล่าร่วมสมัย
2. **ไสยศาสตร์ & หมอผี** — คุณไสย ของขลัง หมอผีปราบผี
3. **นิทานพื้นบ้าน & จักรๆ วงศ์ๆ** — ยักษ์ นางฟ้า ของวิเศษ
4. **ชีวิตสอนใจ** — ดราม่ากรรมตามสนองแบบไม่มีผี
5. **ตลกบ้านทุ่ง** — มุกหักมุม จบด้วยมุกปิด

ทุกเรื่องจบในคลิป: เปิดให้สะดุ้ง → ตั้งเรื่อง → เหตุประหลาด → หักมุม/ผลกรรม → ประโยคปิดสอนใจ · ผีและตัวละครเป็นเรื่องแต่ง ไม่อ้างบุคคลหรือสถานที่จริง

### ระดับความสยอง

เบา / กลาง / เข้ม / สุ่ม (ใช้กับหมวดผีและไสยศาสตร์ — ตั้งต้น "กลาง") ทุกระดับห้ามเปลือยและเรื่องเพศ ห้ามไส้หรือศพแหลก เลือดได้เล็กน้อย

### ลายเส้นและสี

ลายเส้นแบบการ์ตูนเล่มละบาทไทยยุค 2520: หมึกดำ แรเงาเส้นขนาน ลงสีสด ทุกภาพเป็นภาพสี **ภาพต้องไม่ออกเหลือง** — สีสดใสสะอาด ส่วนขาวเป็นขาวบนกระดาษขาว ไม่มีโทนกระดาษเก่า/ซีเปีย แต่ละหมวดมีชุดสีของตัวเอง (ผี/ไสยศาสตร์โทนมืด แดงเลือด เขียวป่า ม่วงกลางคืน · นิทาน ดราม่า ตลกโทนสว่าง)
คำบรรยายเป็นกล่องข้อความแบบการ์ตูน ฟอนต์ Mali (OFL) ฝังมากับแอป · ภาพแรกเป็นแบบปกเล่ม "เล่มที่ N" นับต่อเนื่อง ใช้เป็นภาพตัวอย่างบน TikTok

### Style Kit

ภาพสีตัวอย่างลายเส้น 6 ภาพที่เราวาดเอง (`extension/style-kit/`) แนบให้ Google Flow เป็นแบบลายเส้นของแต่ละช็อต — ไม่มีภาพสแกนเล่มจริงของนักวาดไปกับแอป (ภาพอ้างอิงเก็บเฉพาะในเครื่องเจ้าของ ไม่ขึ้น GitHub และไม่อยู่ใน Setup.exe)

### สวิตช์ inkify (แปลงเป็นงานพิมพ์)

หลังโหลดภาพจาก Flow โปรแกรมปรับให้เป็นงานพิมพ์ในเครื่องด้วยโค้ด (ไม่ใช้ AI ผลคงที่): เส้นหมึกคม แก้ภาพที่ออกเหลืองให้ขาวเป็นขาว เพิ่มความสดเล็กน้อย เม็ดสกรีน/สีเหลื่อมแบบพิมพ์ราคาถูก เปิด/ปิดได้ทีละคลิปที่ "แปลงเป็นงานพิมพ์" ใน ⚡ ตั้งค่าคลิป

### เพลงประกอบ

แอปไม่แถมเพลง — **ใส่ไฟล์ mp3 บรรยากาศของคุณเองลงโฟลเดอร์ `music/`** (สร้างโฟลเดอร์ `music` ในโฟลเดอร์โปรแกรมถ้ายังไม่มี) ระบบสุ่มหยิบจากโฟลเดอร์นี้อัตโนมัติ ถ้าไม่มีไฟล์ ก็ได้คลิปที่ไม่มีเพลง ใช้เฉพาะเพลงที่คุณมีสิทธิ์ใช้

### เสียงพากย์

ตั้งต้นใช้ Edge (ฟรี ไม่ต้องมี key) น้ำเสียงผู้ชายทุ้ม เล่าช้าชวนขนลุก เลือก ElevenLabs / Gemini ได้ที่แผงข้าง (ใส่ API key ของคุณเองตามที่แผงข้างบอก — ไม่มี key ของเจ้าของติดมากับแอป) และเสียงในเครื่อง (ต้องมีการ์ดจอ NVIDIA ติ๊กตอนติดตั้ง)

### Kie (ทำภาพเคลื่อนไหว — ไม่บังคับ)

ตั้งต้น **ปิด** — ภาพนิ่งซูม/เลื่อนกล้อง ไม่เสียเงิน เปิดได้เองเมื่อมี API key ของ Kie โดยเลือกสัดส่วนที่ทำเป็นวิดีโอ 20/60/80/100% **Kie คิดเครดิตตามจำนวนฉาก** (เช่นระดับถูกสุดประมาณ 14 เครดิตต่อฉาก) แถบเครดิตในแผงข้างแสดงยอดคงเหลือ
